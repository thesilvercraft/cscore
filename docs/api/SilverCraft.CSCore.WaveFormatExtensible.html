Class WaveFormatExtensible

Namespace
SilverCraft.CSCore
Assembly
SilverCraft.CSCore.dll

Defines the format of waveform-audio data for formats having more than two channels or higher sample resolutions than allowed by WaveFormat. Can be used to define any format that can be defined by WaveFormat. For more information see http://msdn.microsoft.com/en-us/library/windows/hardware/gg463006.aspx and http://msdn.microsoft.com/en-us/library/windows/hardware/ff536383(v=vs.85).aspx.

SamplesPerBlock

Gets the number of samples contained in one compressed block of audio data. This value is used in buffer estimation. This value is used with compressed formats that have a fixed number of samples within each block. This value can be set to 0 if a variable number of samples is contained in each block of compressed audio data. In this case, buffer estimation and position information needs to be obtained in other ways.

public int SamplesPerBlock { get; protected set; }

ValidBitsPerSample

Gets the number of bits of precision in the signal. Usually equal to BitsPerSample. However, BitsPerSample is the container size and must be a multiple of 8, whereas ValidBitsPerSample can be any value not exceeding the container size. For example, if the format uses 20-bit samples, BitsPerSample must be at least 24, but ValidBitsPerSample is 20.

public int ValidBitsPerSample { get; protected set; }
